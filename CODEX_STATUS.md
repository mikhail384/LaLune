# Результаты первичной проверки

Ветка `codex/lalune-improvements`. Работа по техническому заданию не завершена.

* Flutter: 58 тестов прошли, включая проверки ограничения размера подписки и
  сохранения изменений при обновлении подписки.
* OpenWrt: 20 Rust-тестов прошли, четыре теста требуют отдельного сетевого
  пространства. В Linux-контейнере все шесть интеграционных сценариев прошли
  с тестовым UDP-ядром, включая пакет LAN и firewall4. Настоящий
  OpenWrt-роутер и внешний VPN-трафик не проверены.
* Samsung SM-J510FN: Android 7.1.1, armeabi-v7a, 720x1280, 60 Гц. CSQTTR:
  импорт профиля бота, HTTPS с ростом TUN-счётчиков и переподключение прошли.
  CSQTT 2.5.1: профиль бота 2.5.0 импортирован, но подключение за 60 с не
  завершилось, хотя TURN-сессии создавались.
* HONOR YAL-L41: Android 10, arm64-v8a, 1080x2340, 60 Гц. CSQTTR и
  LaLuneSUB: DNS, HTTP и локальные счётчики проверены. До исправления VPN
  отключался при выключении экрана; после исправления DNS и HTTP проверены
  при погашенном экране.
* Huawei AGS3K-W09: Android 10, arm64-v8a, 1200x1920, 60 Гц. CSQTTR:
  отдельный профиль, DNS и HTTP проверены. Интерфейс подписки и ориентации
  требуют разблокировки планшета и дополнительной проверки.
* APK подписан debug-ключом и содержит CSQTT, CSQTTR, CSQTT 2.1.9 и декодер
  ссылок для arm64-v8a, armeabi-v7a и x86_64. Полная функциональность и x86_64
  ещё не проверены. Официальную подпись он не использует.
* Telegram Bot API подтвердил тестовое сообщение и промежуточный отчёт после
  предыдущих тайм-аутов. Профили CSQTTR и CSQTT получены в Telegram Web;
  секреты профилей не включены в отчёт.
* Mac-раннер GitHub собрал тестовый DMG; SHA-256 подтверждён, окно приложения и
  ответ бэкенда проверены на Apple Silicon. Реальный VPN на macOS не проверен.
  Официальные ядра CSQTT/CSQTTR
  для macOS доступны только в x86-64 и требуют Rosetta на Apple Silicon.
* Отдельная Ubuntu 24.04 в WSL2 создана для проверок. 13 сценариев Linux TUN
  прошли с эхо-ядром; реальное подключение Linux пока не проверено. Отдельная
  Windows VM не обнаружена.

Локальная тестовая подписка на Samsung прошла добавление, обновление,
подключение, учёт приёма/отдачи и сохранение счётчиков после перезапуска.
Трафик обычного профиля не попал в счётчик подписки. При отключении между
периодическими опросами часть трафика может не учитываться; восстановление
непрерывного VPN при перезапуске интерфейса требует дополнительной проверки.
Профилирование до/после, пакет macOS, реальные подключения и проверка ramips
остаются невыполненными.
