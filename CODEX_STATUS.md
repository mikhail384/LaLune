# Результаты первичной проверки

Ветка `codex/lalune-improvements`. Работа по техническому заданию не завершена.

* Flutter: 58 тестов прошли, включая проверки ограничения размера подписки и
  сохранения изменений при обновлении подписки.
* OpenWrt: 20 Rust-тестов прошли, четыре теста требуют отдельного сетевого
  пространства. В Linux-контейнере все шесть интеграционных сценариев прошли
  с тестовым UDP-ядром, включая пакет LAN и firewall4. Настоящий
  OpenWrt-роутер и внешний VPN-трафик не проверены.
* Samsung SM-J510FN: Android 7.1.1, armeabi-v7a, 720x1280, 60 Гц.
* HONOR YAL-L41: Android 10, arm64-v8a, 1080x2340, 60 Гц.
* Huawei AGS3K-W09: Android 10, arm64-v8a, 1200x1920, 60 Гц.
  На всех трёх установлена тестовая сборка и запущена основная Activity.
  Подключение и производительность не проверены.
* APK подписан debug-ключом. В локальной сборке отсутствуют необходимые ядра
  для части сочетаний архитектур и протоколов: считать APK полноценным
  универсальным нельзя. Официальную подпись он не использует.
* Telegram Bot API подтвердил тестовое сообщение и промежуточный отчёт после
  предыдущих тайм-аутов. Автоматическая
  проверка среды отклонила открытие бота тестовых конфигураций на Samsung;
  тестовые конфигурации не получены.
* Mac и отдельные Windows/Linux VM не обнаружены. Docker Linux-контейнер
  использован для тестов и не заменяет полноценную проверку Linux VM.

Добавлено сохранение раздельных локальных счётчиков приёма и отдачи; старая
общая статистика сохраняется без искусственного распределения. Учёт при
отключении и перезапуске приложения требует доработки и проверки реальным
подключением. Обновление не удаляет профиль активного подключения; отложенная
очистка требует дополнительной проверки.
Профилирование до/после, пакет macOS, реальные подключения и проверка ramips
остаются невыполненными.
