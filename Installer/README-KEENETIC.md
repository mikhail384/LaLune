# Установка и запуск LaLune на KeeneticOS

Данная инструкция описывает установку и запуск клиента LaLune на роутерах под управлением официальной **KeeneticOS** через систему пакетов **Entware (OPKG)**.

> [!NOTE]
> Перепрошивка роутера **НЕ требуется**. Роутер остаётся на заводской KeeneticOS. Установка происходит в изолированную пользовательскую среду Entware, окирпичивание аппаратно исключено.

---

## Поддерживаемые устройства

| Модель / Серия | Архитектура | Установка Entware | Целевая сборка |
|---|---|---|---|
| **Speedster (KN-3012 / KN-3010)** | `mipsel` (EN7561DU / MT7621) | **Внутренняя память** (`storage:`) | `lalune-openwrt-backend-ramips` |
| **Air (KN-3110)** | `mipsel` (MT7628) | **Внутренняя память** (`storage:`) | `lalune-openwrt-backend-ramips` |
| **4G (KN-1211)** | `mipsel` (MT7628NN) | USB-накопитель или внутренняя память | `lalune-openwrt-backend-ramips` |
| **Giga (KN-1010), Viva (KN-1910), Hopper (KN-3810)** | `mipsel` (MT7621) | USB-накопитель или встроенная память | `lalune-openwrt-backend-ramips` |
| **Titan (KN-1811), Peak (KN-2710)** | `aarch64` (MT7986 / MT7622) | USB-накопитель | `lalune-openwrt-backend` |
| **Ultra (KN-2410), Giga (KN-1011)** | `armv7` (Cortex-A7) | USB-накопитель | `lalune-openwrt-backend-armv7` |

---

## 1. Подготовка роутера (на примере Speedster KN-3012 без USB)

У роутера Keenetic Speedster нет USB-порта, поэтому Entware устанавливается во внутреннюю NAND флеш-память (раздел `storage` на файловой системе UBIFS).

### Шаг 1.1: Включение компонентов в веб-интерфейсе
1. Откройте панель роутера: `http://192.168.1.1`
2. Перейдите в **Управление** → **Общие настройки** → **Изменение набора компонентов**.
3. Убедитесь, что установлены компоненты:
   - **Поддержка открытых пакетов (OPKG)**
   - **Протокол OpenVPN** (включает системный модуль ядра `tun.ko`)
4. Если компоненты не были установлены, нажмите **Установить** и дождитесь перезагрузки роутера.

### Шаг 1.2: Активация Entware во внутренней памяти
1. Перейдите в **Управление** → **Системные файлы**.
2. Откройте раздел **storage**.
3. Создайте в нём папку с именем `install`.
4. Скачайте официальный архив установщика:
   - Для KN-3012 (MIPS): `https://bin.entware.net/mipselsf-k3.4/installer/mipsel-installer.tar.gz`
5. Загрузите скачанный файл `mipsel-installer.tar.gz` в созданную папку `install` через веб-интерфейс.
6. Откройте веб-консоль `http://192.168.1.1/a` или подключитесь по SSH к роутеру:
   ```text
   opkg disk storage:/
   ```
7. В **Диагностика** → **Системный журнал** появится сообщение:
   `installer: [5/5] Установка системы пакетов «Entware» завершена!`

## 2. Быстрая установка LaLune (One-Liner)

Подключитесь к роутеру по SSH (порт `222` или стандартный SSH в Entware: `ssh root@192.168.1.1`):

```sh
curl -fsSL https://raw.githubusercontent.com/mikhail384/LaLune/feature/keenetic-openwrt-router-support/Installer/keenetic.sh | sh
```

Что делает скрипт:
- Определяет архитектуру чипа роутера (для KN-3012 выберет `ramips` MIPS);
- Проверяет и доустанавливает из Entware утилиты `ip-full`, `iptables`, `ca-certificates`;
- Проверяет устройство туннелирования `/dev/net/tun`;
- Скачивает оптимизированный бинарник `lalune-backend` в `/opt/bin/`;
- Создаёт службу автозапуска `/opt/etc/init.d/S99lalune`;
- Автоматически запускает сервис.

## 3. Управление и веб-интерфейс

### Веб-панель LaLune:
Откройте в браузере:
```text
http://192.168.1.1:1062/panel
```
В панели доступно:
- Статус туннеля и трафика в реальном времени;
- Выбор протокола и профилей подключения;
- Журнал событий и логи ядра.

### Управление через консоль:
```sh
/opt/etc/init.d/S99lalune start    # Запуск службы
/opt/etc/init.d/S99lalune stop     # Остановка службы
/opt/etc/init.d/S99lalune restart  # Перезапуск
/opt/etc/init.d/S99lalune status   # Проверка статуса
```

### Просмотр логов:
```sh
cat /opt/var/log/lalune.log
```

## 4. Управление из мобильного приложения LaLune

Вы можете управлять роутером прямо с телефона:
1. Подключите смартфон к домашней Wi-Fi сети роутера Keenetic.
2. Откройте мобильное приложение **LaLune** (Android или iOS).
3. В настройках или окне роутера укажите адрес: `192.168.1.1:1062`.
4. Смартфон станет пультом дистанционного управления для роутера.

---

## 5. Полное удаление

Если вы решите удалить LaLune:
```sh
curl -fsSL https://raw.githubusercontent.com/mikhail384/LaLune/feature/keenetic-openwrt-router-support/Installer/keenetic.sh | sh -s -- --uninstall
```
Или просто выключите тумблер **«Менеджер пакетов OPKG»** в веб-интерфейсе Keenetic — раздел моментально отмонтируется, и роутер вернётся в заводское состояние.
