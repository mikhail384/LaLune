# LaLune для macOS без Metal

Экспериментальная сборка с исходным Flutter UI во встроенном WebKit. HTML-отрисовка позволяет открыть интерфейс на Mac без работающего Metal. Для карточек используется предварительно размытая копия фона; она не размывает произвольный контент за карточкой.

## Сборка

Нужны macOS, Apple Command Line Tools (включая Python 3 и Swift), Rust/Cargo и **Flutter 3.24.5** с веб-инструментами. Выполните из корня репозитория:

```sh
FLUTTER=/путь/к/flutter/bin/flutter ./Mac/NoMetal/build.sh
```

Результат: `Output/LaLune-NoMetal.app`. Сборка берёт исходники LaLune из зафиксированного коммита `412d9b37548a269690dffd214d4218195158516e`, а не из текущего состояния основной ветки. Поэтому новые функции, добавленные после этого коммита, сюда не входят. Версия на этом Mac запускалась с Intel; Apple Silicon и реальное VPN-подключение не проверены. Ядра для Intel загружаются при подключении; на Apple Silicon может понадобиться Rosetta. Подписки и функции OpenWRT не проверены в веб-среде.

Приложение не нотариализовано и запрашивает права администратора для VPN. Его локальный API защищён отдельным ключом; внешний WebKit обращается через локальный прокси. Чтобы приложение могло запуститься на другом Mac, на нём также должны быть установлены инструменты командной строки Apple, предоставляющие `/usr/bin/python3`.

`dartssh2` 4.1.0 скачивается с pub.dev с проверкой SHA-256; при сборке его требование к пакету `meta` снижается с 1.16 до 1.15 для совместимости с Flutter 3.24. Это локальная сборочная адаптация, не проверка совместимости SSH/OpenWRT.
